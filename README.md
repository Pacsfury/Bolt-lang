# Bolt Language

A language made to be fast and simple.

---

## Building with CMake

Build the language compiler and VM independently from the repository root:

```bash
cmake -S . -B cmake-build
cmake --build cmake-build --target bolt
cmake --build cmake-build --target bvm
```

The `frontend` and `backend` libraries can also be built on their own:

```bash
cmake --build cmake-build --target frontend
cmake --build cmake-build --target backend
```

The executables are written to the build directory (`bolt`/`bolt.exe` and
`bvm`/`bvm.exe`). The VM reads `main.bvm` from its current working directory.

To package a program as one self-extracting executable, run
`bolt packace` from the repository root. By default it reads `BVM-CPOOL`,
`main.bvm`, and `vm/bvm.exe`, and creates `program.exe`. You can also pass
the four paths in that order:

```bash
bolt package -C BVM-CPOOL -B main.bvm -vm vm/bvm.exe -o BoltProgram.exe
```

You can just run `bolt package` if the paths match these: `BVM-CPOOL`, `main.bvm`, `vm/bvm`/`vm/bvm.exe`, `program`/`program.exe`

The executable is the vm executable with the other data appended to it.

## Run modes

Currently, Bolt has five different modes of running code:

1. build

```bash
bolt build in -o out
```
Writes the bytecode

2. debug

```bash
bolt debug in -o out
```
Writes the bytecode and prints the tokens and the AST

3. time

```bash
bolt time in -o out
```
Writes the bytecode and prints the time taken at every stage

4. direct

```bash
bolt -d "var name = 'a';" -o out
```

5. check

```bash
bolt check in -o out
```
Useful for IDE/editor checkers, builds and checks the AST, but generates no bytecode.

---

In all three modes, `in` is `main.blt` if not specified and `out`, `main.bvm`.

These modes are not currently combinable. None of this modes executes it yet.

## Expected Syntax

> Syntax may vary, as Bolt is in an early stage of development

```
fn add(a: i32, b: i32) -> i32 {
    ret a+b;
}

var n1: int = 123; // int is an alias for i32
var n2: int = 494;

print(add(n1, n2)); // This print method is a placeholder for future print methods

```

### write

```
write "string or char";
```

### variables

```
var name = 'a';
var points: i16 = 45;
```

Write and simple variables are working!

## How to compile and run your program

1. Write your program

We will use this as an example:

`main.blt`
```
write "hello, world!";
```

2. Compile with Bolt

```bash
bolt run main.blt -o main.bvm
```

3. Package

```bash
bolt package -vm vm/bvm.exe -o program.exe # replace paths!
```

You will see something like this:
```
hello, world!

VM Execution time: 130000 nanoseconds.
Or: 0.1300 ms.
```

> Note: the vm uses `puts` and reads the CPOOL file, so using write is kinda slow. For raw speed, package your code to a standalone executable!

## Bolt can
* use write, var and const with strings and chars
* compile the generated bytecode to a standalone executable file
* easily get an executable for other platforms
